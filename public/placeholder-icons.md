# PWA Icons Needed

For the Packet PWA to work properly on iPhone Safari and other devices, we need the following icons:

## Required Icons

1. **pwa-192x192.png** - 192x192 pixel icon
2. **pwa-512x512.png** - 512x512 pixel icon  
3. **pwa-maskable-192x192.png** - 192x192 maskable icon
4. **pwa-maskable-512x512.png** - 512x512 maskable icon
5. **apple-touch-icon.png** - 180x180 for iOS (can use pwa-192x192.png)
6. **favicon.ico** - 32x32 favicon

## Shortcut Icons

7. **icon-add.png** - 96x96 for "Add New Place" shortcut
8. **icon-places.png** - 96x96 for "View Places" shortcut  
9. **icon-map.png** - 96x96 for "Map View" shortcut

## Screenshots (for App Store-like listing)

## Design Guidelines

- **Primary color:** #8b5cf6 (purple)
- **Secondary color:** #ec4899 (pink)
- **Style:** Clean, modern, food-related
- **Logo concept:** Two forks/spoons crossing, or a heart with food elements

## Temporary Placeholders

For development, you can use:
- Any 192x192 and 512x512 images
- Generate at: https://realfavicongenerator.net/
- Or create simple colored squares with text "P"

## iOS Specific Notes

- iOS requires `apple-touch-icon.png` at 180x180
- iOS doesn't support maskable icons
- iOS install process is different (Share → Add to Home Screen)
