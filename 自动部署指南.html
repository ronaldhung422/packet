2
设置 Supabase（数据库）
Supabase 提供免费 PostgreSQL 数据库和实时同步功能：
  1. 访问 https://app.supabase.com
  2. 点击 "New Project"
  3. 输入项目名称: packet-app
  4. 设置数据库密码
  5. 选择离你最近的地区
  6. 点击 "Create new project"
  7. 等待项目创建完成
  8. 进入 Settings → API，复制：
    • Project URL
    • anon/public key
🚀 前往 Supabase
3
设置 Cloudflare Worker
Cloudflare Worker 用于 Instagram 链接提取（绕过 API 限制）：
  1. 访问 https://dash.cloudflare.com
  2. Workers & Pages → Create application
  3. 点击 "Create Worker"
  4. 名称: packet-extraction-worker
  5. 点击 "Deploy"
  6. 进入 Workers → 你的 Worker → Edit code
  7. 复制文件内容：workers/extraction-worker/src/index.js
  8. 粘贴并点击 "Save and Deploy"
  9. 记下 Worker URL
⚡ 前往 Cloudflare
4
部署到 Vercel
Vercel 提供免费的静态网站托管和全球 CDN：

选项 A：使用 Vercel 控制台（推荐）

  1. 访问 https://vercel.com
  2. 点击 "Add New" → "Project"
  3. 如果没有 GitHub 仓库，直接上传项目文件夹
  4. 配置：Framework Preset = Vite
  5. 添加环境变量（见下方）
  6. 点击 "Deploy"

选项 B：使用 Vercel CLI

npm install -g vercel
vercel login
vercel
vercel --prod
🌐 前往 Vercel
5
环境变量配置
在 Vercel 部署时，需要设置以下环境变量：
VITE_SUPABASE_URL=https://你的项目.supabase.co
VITE_SUPABASE_ANON_KEY=你的匿名密钥
VITE_EXTRACTION_WORKER_URL=https://packet-extraction-worker.你的用户名.workers.dev
重要提示
这些变量必须正确设置，否则应用无法连接到数据库和提取服务。
6
测试与使用
部署完成后，进行以下测试：
  1. 访问你的部署 URL（如：https://packet.vercel.app）
  2. 在 iPhone Safari 中：
    • 点击分享按钮 (📤)
    • 选择"添加到主屏幕"
    • 确认安装
  3. 测试 Instagram 链接提取
  4. 测试设备配对功能
  5. 与 Kerry 分享使用
